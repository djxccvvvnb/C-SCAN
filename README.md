# C-SCAN

Windows 平台 TCP 端口扫描器，纯控制台交互，无需命令行参数。

## 编译运行

**编译器：** MinGW-w64 (gcc) 或 MSVC

```bash
# MinGW-w64
gcc -o C-SCAN.exe main.c -lws2_32 -O2

# MSVC
cl main.c ws2_32.lib
```

运行：

```bash
.\C-SCAN.exe
```

程序启动后全程交互式输入，无需传参。

## 安全警告

> **本程序仅允许扫描自己拥有权限的设备。**
> 未经许可扫描他人网络属于违法行为，请合法使用。

## 功能说明

- 支持 IP 地址或域名作为目标（域名通过 `getaddrinfo` 解析）
- TCP-Connect 完整连接扫描（非阻塞 socket + `select` + 超时控制）
- 内置常用 32 个端口 / 自定义端口（单个或范围，如 `1-1000`）
- 只输出开放端口，排版模仿 Nmap 风格

## CDN 解析限制

当输入域名时，程序仅输出 DNS 解析得到的 IP 地址，**不会自动识别是否为 CDN 节点**。
若目标使用了 CDN（如 Cloudflare、Akamai 等），解析出的 IP 可能是 CDN 边缘节点，而非源站真实 IP。
此时扫描结果仅代表 CDN 节点开放了哪些端口，**不代表目标源站的端口状态**。
请在扫描前确认目标是否经过 CDN 代理。

## 约束

- 仅适配 Windows（Winsock API）
- 不实现 SYN/FIN/NULL/Xmas 扫描
- 不实现服务识别、操作系统探测等高级功能
- 不引入任何第三方库
